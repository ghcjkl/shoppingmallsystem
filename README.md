# 优购商城（连锁茶饮零食电商）

前后端分离的连锁茶饮/零食商城，覆盖顾客端与门店管理端双端业务。

## 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 3.2 · MyBatis-Plus · MySQL 8 · Redis（Lettuce）· JWT |
| 前端 | Vue 3 · Element Plus · Pinia · Vite |
| 工程 | Maven · RESTful API · 统一响应结构与全局异常处理 |

## 核心功能

**顾客端**
- 商品分类与检索、商品详情（SKU 规格、加料、制作选项：冷热/甜度/冰量）
- 购物车（按「商品 + 规格 + 加料 + 制作选项」组合合并）、下单结算
- 订单状态流转：待支付 → 已支付 → 制作中 → 待取餐 → 已完成 / 售后
- 取餐码核销、站内取餐通知（轮询 + 红点）
- 余额充值（赠送档位后端配置化）、优惠券、会员积分与成长值
- 订单评价（一单一项一评，含管理端回复）

**门店管理端**
- 商品/分类/SKU/原料库存管理，入库出库流水
- 订单看板（排队叫号、制作明细、取餐核销）
- 经营看板：销售额/订单量趋势、时段分布、分类销售结构、新客占比、退款率
- 售后工单处理（退款金额服务端校验上限）、评价管理、充值档位配置

## 技术要点

- **并发防超卖**：库存扣减采用数据库原子条件更新（`UPDATE ... SET stock = stock - ? WHERE stock >= ?`），下单扣 SKU、支付扣原料、取消/售后回补全链路闭环，20 并发实测无超卖
- **Redis 热点缓存**：商品列表/详情、看板统计走缓存；TTL 随机抖动防雪崩、SCAN 游标分批失效、写操作精确失效；缓存故障时失败计数 + 30s 熔断降级回源
- **安全边界**：JWT + 拦截器鉴权、ThreadLocal 用户上下文、订单归属校验防越权；退款金额（≤ 实付 − 已退）与储值退回上限服务端校验；商品价格/制作选项/赠送额一律服务端回查计价，客户端不可伪造
- **订单快照**：下单时锁定价格与规格文案，商品改价不影响历史订单
- **取餐码**：6 位随机码，同店未完结订单范围内查重防撞码

## 目录结构

```
backend/    Spring Boot 后端（src/main/java/com/shoping 下按业务模块组织）
frontend/   Vue 3 前端（src/views 顾客端 + 门店管理端，Pinia 状态管理）
```

## 快速启动

1. **数据库**：创建 MySQL 库 `shoping`，执行 `backend/db/schema.sql`（含建表与种子数据）
2. **后端**：修改 `backend/src/main/resources/application.yml` 中的数据库/Redis 连接后启动，默认端口 8080
3. **前端**：
   ```bash
   cd frontend
   npm install
   npm run dev    # http://localhost:5173
   ```
4. 默认账号：`admin / 123456`（管理端）、`user / 123456`（顾客端）

> 注：Redis 可选，未启动时缓存层自动降级直查数据库。
